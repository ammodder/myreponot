## §4 FINDINGS (sorted by severity)

**A3-02 · Severity: MAJOR · Location: AndroidManifest.xml:29,31 + AppNavigator.kt:19-41 + grep rememberSaveable (a3-grep-controls.log §7)**
Steps to reproduce: (1) open any non-auth screen, e.g. half-fill EditProfile or Tournaments filter; (2) change system font size / system dark mode / display size (uiMode/fontScale config change) → Activity recreates (no configChanges).
