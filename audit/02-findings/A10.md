## 2. 16 KB PAGE SIZE — verdict: **COMPLIANT (measured), not "N/A-by-construction"**

**The task premise ("expect ZERO native libraries") is factually wrong** — but the app is still 16 KB compliant. Measured (a10-16kb-page-size.log):

- `unzip -v` on BOTH APKs: exactly **8 `.so` files** (4 ABIs × 2 libs), all `Stored` (uncompressed; merged manifest `extractNativeLibs=false`, a10-release-manifest-tree.log:49):
  - `libandroidx.graphics.path.so` (10,096 B arm64 / 7,252 armeabi-v7a / 9,284 x86 / 10,760 x86_64) — transitive via Compose UI (androidx.graphics:graphics-path 1.0.1 in gradle cache).
  - `libdatastore_shared_counter.so` (7,112 / 4,416 / 5,148 / 6,224 B) — transitive via androidx.datastore 1.1.1.
  - Sizes: every lib is 4.4–10.8 KB — smaller than one 16 KB page; each file is <16 KB total.
- **ELF `PT_LOAD` alignment parsed from the extracted files (python ELF-header parser, inline in the run transcript): ALL LOAD segments across all 8 libs have `p_align = 0x4000 (16384)` → 16 KB-aligned.** This is the exact property the Play check tests (16 KB-page loadable without relinking).
- Build-config corroboration: 0 matches for `externalNativeBuild|abiFilters|cmake|ndkVersion|jniLibs` in `app/build.gradle.kts` / `gradle.properties` (a10-config-citations.log); no `app/src/main/jniLibs/**` (glob empty). The two libs are inherited prebuilt AndroidX artifacts, not project natives.
- Dependency purity check: `com.google.zxing:core:3.5.3` ships as a plain **JAR** (332 class files); `io.coil-kt:coil-compose:2.7.0` AAR contains `classes.jar` only, **no `.so`**; `zxing-android-embedded:4.3.0` AAR has no `lib/` dir. Confirms Coil/ZXing are pure JVM — they will never introduce page-size risk themselves.

**Play 16 KB requirement (searches `a10-16kb.json`):** *"Starting November 1, 2025, all new apps and updates submitted to Google Play targeting Android 15+ must support 16 KB page sizes"* (android-developers.googleblog.com May 8 2025; issuetracker 424476473; uno/platform posts); developer.android.com: *"all apps targeting Android 15 (API level 35) and higher must support 16 KB memory page sizes on 64-bit devices on Google Play"*. Existing-app enforcement cited in Console warnings as "not allowed to be published after May 2026" (support thread) — official existing-apps date Nov 1 2026 per the page-sizes guide (Console wording = NOT VERIFIED, account needed).

**Verdict: compliant, nothing to do — UNLESS a third-party dependency ever ships native code** (then re-run `unzip -v` + ELF p_align check; the shipped `lib/*` list must stay 16 KB-aligned and the 4-ABI set stays as-is). Graded as A10-02 (NOTE — premise correction + measured compliance).
